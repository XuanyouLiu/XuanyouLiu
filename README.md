## Research Interests

- **Embodied AI:** wearable interactive systems and context-aware assistants that act proactively or share initiative with the user
- **Multimodal sensing:** compact wearables, including EIT and IMUs, that infer user and environmental state
- **Mixed-initiative assistance:** when and how an assistant should share initiative, posed as a decision-making problem with models of human behavior as priors
- **On-body haptics:** electrotactile stimulation and EMS that deliver assistance as physical feedback
